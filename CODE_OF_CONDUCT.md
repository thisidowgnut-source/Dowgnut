# Dowgnut Code of Conduct

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

## Standard
Participants are expected to communicate professionally, respectfully, and constructively.

Unacceptable behavior includes harassment, discrimination, threats, malicious disclosure of private information, deliberate disruption of project infrastructure, and abusive conduct toward maintainers or contributors.

## Enforcement
Project maintainers may remove comments, close issues or PRs, revoke repository access, or take other proportionate action.

## Reporting
For private conduct concerns, use the repository owner’s private GitHub communication channel. Do not post sensitive information in public issues.
