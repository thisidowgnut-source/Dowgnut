# Documentation Standard

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

Every normative document MUST contain title, status, review date, source of truth, purpose, scope, authoritative requirements, and references where external facts are used.

Documents SHOULD be task-oriented and avoid duplicate conflicting requirements.

When a requirement changes, update the canonical document and link from derivative docs instead of copying the requirement into many places.
