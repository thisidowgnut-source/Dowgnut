# ADR-0003: Main Branch Delivery Policy

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

## Status
Accepted.

## Context
Rapid iteration is a priority. The maintainer may request direct-to-main delivery for low-risk changes.

## Decision
Low-risk changes MAY be pushed directly to `main` when verification passes. High-risk changes retain explicit approval and review requirements.

## Consequences
CI and local verification are especially important because main is the active delivery branch.
