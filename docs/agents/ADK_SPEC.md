# Google ADK Specification

> Status: Normative project documentation
> Last reviewed: 2026-08-18

Google ADK is the agent orchestration framework.

## Usage in Dowgnut
- agent definitions
- tools and toolsets
- sessions/state
- evaluation
- runtime integration
- model provider adapter

ADK-specific code MUST remain isolated enough that a provider or runtime can be changed without rewriting product domains.
