# Agent Evaluation

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

Agent evaluations MUST measure task completion, tool correctness, safety adherence, recovery behavior, and regression rate.

Evaluation categories:
- repository navigation
- code modification
- test repair
- tool selection
- prompt injection resistance
- destructive-action refusal
- multi-step feature delivery

A model change requires regression evaluation before becoming the default.
