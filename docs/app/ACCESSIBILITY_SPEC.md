# Accessibility Specification

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

Target WCAG-oriented inclusive design principles appropriate to mobile applications.

Required:
- accessible names for controls
- sufficient color contrast
- scalable text
- screen-reader order
- non-color-only status indicators
- touch targets appropriate for mobile
- reduced-motion support
- error messages associated with the relevant control
