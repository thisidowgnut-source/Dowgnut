# Design System

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

## Tokens
Maintain centralized tokens for:
- colors
- typography
- spacing
- radii
- elevation
- motion
- icon sizing

## Accessibility
Text contrast, touch target sizes, semantic labels, dynamic font scaling, reduced-motion behavior, and keyboard navigation where applicable MUST be considered.

Design tokens SHOULD be implemented once and reused across screens and generated UI.
