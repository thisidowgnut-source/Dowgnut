# Visual Reference Protocol

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

The uploaded reference image is a visual source-of-truth for the initial storefront aesthetic.

Before calling a screen complete:
- compare layout hierarchy
- compare spacing rhythm
- compare typography hierarchy
- compare card proportions
- compare button hierarchy
- compare image treatment
- inspect responsive behavior

Visual fidelity must coexist with accessibility and functional correctness.
