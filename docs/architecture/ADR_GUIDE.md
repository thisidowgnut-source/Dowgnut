# Architecture Decision Record Guide

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

ADRs record decisions that would otherwise be repeatedly rediscovered.

Each ADR MUST contain:
- Context
- Decision
- Alternatives
- Consequences
- Security impact
- Migration/rollback plan
- Status
- Supersession link when applicable

Use sequential IDs and never rewrite historical decisions; supersede them with a new ADR.
