# Change Management

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

Every significant change SHOULD be classified by risk, affected domains, migration needs, and rollback complexity.

Change record fields:
- objective
- scope
- affected systems
- dependencies
- test evidence
- security impact
- rollout strategy
- rollback strategy
