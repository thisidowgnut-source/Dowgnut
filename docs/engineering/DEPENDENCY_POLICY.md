# Dependency Policy

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

Before adding a dependency, evaluate:
- maintenance activity
- security history
- license
- bundle/runtime cost
- platform compatibility
- overlap with existing dependencies
- lockfile impact

Prefer official SDKs and well-maintained libraries. Remove dead dependencies.
