# Music and Social Integration Plan

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

Planned integrations include Spotify, Shazam, TikTok, YouTube, YouTube Music, Facebook, and Instagram.

Each integration MUST be reviewed for:
- official API availability
- authentication scope
- commercial usage rights
- rate limits
- data licensing
- user-consent requirements
- caching rules
- platform policy

No integration should scrape protected endpoints when an official API is available.
