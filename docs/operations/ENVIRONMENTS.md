# Environment Strategy

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

## Environments
- local
- development
- staging
- production

Each environment has separate credentials and data.

Production data MUST NOT be used for test automation.

Environment configuration is documented by variable name, owner, source, required/optional status, and secret classification.
