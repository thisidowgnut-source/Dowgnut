# Incident Response

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

## Severity
SEV-1: data loss/security/payment outage
SEV-2: major feature outage
SEV-3: degraded experience
SEV-4: minor defect

## Procedure
Detect → triage → contain → communicate → recover → validate → document → prevent recurrence.

For security incidents, preserve evidence and avoid public disclosure until the responsible maintainers have assessed impact.
