# Release Scope

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

Every release MUST declare:
- included features
- excluded features
- known limitations
- migration requirements
- rollback plan
- test evidence
- observability changes
- security impact

A release that changes money movement or permissions requires explicit security and product review evidence.
