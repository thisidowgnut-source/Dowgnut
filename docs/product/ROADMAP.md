# Product Roadmap

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

## Phase 0 — Foundation
Repository, Expo scaffold, agent scaffold, NVIDIA provider abstraction, initial AG-UI/ADK runtime.

## Phase 1 — Commerce MVP
Catalog, details, cart, navigation, UI fidelity, test baseline.

## Phase 2 — Backend
Supabase Auth, products, inventory, orders, RLS, persistence.

## Phase 3 — AI commerce
Build My Box, product recommendation, shared cart state, approval and A2UI.

## Phase 4 — Autonomous development
GitHub tools, test/fix loop, screenshot regression, CI feedback, task orchestration.

## Phase 5 — Production
Payments, monitoring, analytics, release automation, operational runbooks.

Roadmap dates are intentionally omitted until execution capacity and external dependencies are measured.
