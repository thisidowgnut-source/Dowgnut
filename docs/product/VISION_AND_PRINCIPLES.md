# Vision and Product Principles

> Status: Normative project documentation
> Last reviewed: 2026-08-18
> Source of truth: `thisidowgnut-source/Dowgnut`

## Vision
Dowgnut is a playful, fast, AI-native doughnut commerce experience where users can discover flavors, compose boxes, order products, and interact with an intelligent assistant without leaving the product flow.

## Principles
1. **Taste before complexity** — the first user action should be obvious.
2. **AI is a capability, not a separate silo** — AI can participate in discovery, composition, cart, support, and operations.
3. **Real state over fake demos** — actions must update real application state.
4. **Fast feedback** — streaming and optimistic UI SHOULD be used where safe.
5. **Reuse before rebuild** — upstream AG-UI, ADK, A2UI, Expo, and Supabase capabilities SHOULD be adapted rather than recreated.
6. **Secure by default** — authorization lives at the real data boundary.
7. **Observable autonomy** — agent actions MUST be inspectable and auditable.
